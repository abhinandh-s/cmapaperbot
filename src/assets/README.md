# Thumbnail Image

From 28 July - 2026, for all new uploads we use the 320x320 one.

![thumbnail 190x190](./thumbnail_190x190.jpeg)

### thumbnail_320x320 - 7KB

![thumbnail 320x320](./thumbnail_320x320.jpeg)




> [!IMPORTANT]
> - image must be of `.jpeg` format
> - size should not exceed 320x320 px


> [!NOTE] 
>
> While senting a file using its file_id, we can't assign new thumbnail. Therefore, we must upload file with thumbnail.
>
> To assist that, the bot have a batch mode command(`/batch start` admin only). Simplify sent the files to the bot while in batch mode, the bot will return the same with thumbnail. 
>
> On `/batch done` cmd, bot will provide `.json` file with the file_id's of new file's with thumbnail.
